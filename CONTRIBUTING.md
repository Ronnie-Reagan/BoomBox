# Contributing to BoomBox

Thanks for taking an interest in BoomBox. This is my first personal project that I’m opening up to contributors, so if you're here to help out—welcome.

---

## 🔧 Fix What You Can  
If you notice something broken, feel free to fix it. Bugs, edge cases, weird behavior—any cleanup or improvements are appreciated.

## ✨ Implement What You Want  
Have a feature idea or a QoL improvement? Want to overhaul something? Add it. As long as it’s useful, doesn’t wreck anything, and works, I’ll happily look at it.

## 🧪 Pull Requests  
Open as many PRs as you want. Just make sure the changes work on your end first. If it’s a big change or you're not sure it fits, feel free to open a discussion or issue first.

## 📁 Code Structure  
Right now everything lives inside `main.py` and it's kind of messy, I know. It’ll eventually be broken out into modules, but for now just follow the existing structure.

If you're adding a whole new feature or system, feel free to make your own module and import it. Just keep it clean, clear, and self-contained.

## 💬 Style & Process  
No strict rules here. Just keep things readable and don’t break stuff. If you leave helpful comments or notes, even better.

---

That’s it. If you’ve got something to contribute, jump in. I’m still building this out and learning as I go, so all input is welcome.
